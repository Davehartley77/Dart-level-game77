# Recorded caller clips (optional)

Drop MP3 files in this folder and the game plays them instead of the synthetic
voice for that moment. Any file that is missing simply falls back to the
built-in caller, so record as many or as few as you like.

| File            | Played when                                   |
|-----------------|-----------------------------------------------|
| `180.mp3`       | a player scores 180                           |
| `ton.mp3`       | a score of 100 to 139                         |
| `gameshot.mp3`  | a checkout in 501, or a win in Saved by the Bull |
| `bigfish.mp3`   | a 170 checkout                                |
| `bust.mp3`      | a bust in 501                                 |
| `saved.mp3`     | a Saved by the Bull                           |
| `gameon.mp3`    | reserved for the start of a game              |

Record on a phone, export as MP3, name the file exactly as above, and put it
here on GitHub. The website picks it up within a minute of the push.
